### Getting started

```bash
git clone https://github.com/Raimal-Raja/dart.git
cd dart
```

With the Dart SDK installed, run a standalone example:

```bash
dart run arthmetic.dart
```

The Dart SDK was unavailable for runtime verification.

### Configuration and limitations

Run one example at a time with the Dart SDK. These are standalone language exercises; the repository is not a Flutter application.
